# Nikitha C M — Developer Portfolio

A responsive portfolio website made with HTML5, CSS3, and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling and dark/light themes
- `script.js` — mobile menu, theme toggle, project modals, email copy
- `README.md` — setup and deployment instructions

## Run locally
1. Extract the ZIP file.
2. Open the `developer_portfolio` folder.
3. Double-click `index.html` to open it in a browser.
4. For development, you can use Visual Studio Code with the Live Server extension.

## Personalize before publishing
Search for and replace these placeholders:
- `your.email@example.com` in `index.html` and `script.js`
- `https://www.linkedin.com/` with your LinkedIn profile URL
- `https://github.com/` with your GitHub profile URL
- Update project descriptions, skill levels, and links to match work you have actually completed.
- To add a resume, place your PDF in this folder (for example `resume.pdf`) and add a link to it in the hero section.

## Deploy to GitHub Pages
1. Create or sign in to a GitHub account and make a new repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the published URL to appear in the Pages section.

## Deploy to Netlify
1. Open Netlify and sign in.
2. Choose **Add new site → Deploy manually**.
3. Drag the extracted project folder (or the three site files) into the deployment area.
4. Open the generated site URL to test it.

## Deploy to Vercel
1. Push the files to a GitHub repository.
2. Sign in to Vercel and import that repository.
3. Keep the default settings for a static HTML site and click **Deploy**.

No build step or framework is required.
