# Taskflow — Dynamic Task Manager

Ready-to-run responsive CRUD task manager built with HTML, CSS, vanilla JavaScript, and browser localStorage.

## Run
1. Extract the ZIP.
2. Open `dynamic_task_manager/index.html` in a modern browser.
3. Create tasks, edit/delete them, mark complete, filter, and reload to verify persistence.

Files: `index.html` (layout), `style.css` (responsive styling/themes), `script.js` (CRUD, filtering, search, localStorage).

Features: Work/Personal/Study/Other categories, optional due dates, All/Active/Completed filters, category filter, live search, completion stats, dark/light theme, edit modal, clear completed, responsive layout, and no server dependency.

Tasks are stored in this browser profile only under `taskflow-tasks-v1`. They are not synced. Clearing browser site data or using another browser/profile may remove or hide them.

## Publish
This is a static website. Upload the three site files to a GitHub repository and enable GitHub Pages, or deploy the folder using Netlify or Vercel.
